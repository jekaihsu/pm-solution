# 調查發現：R03 報告檢查、R06 請款、R02 業主進度（item 6）

調查日期：2026-10-20。以下三處「沒有資料／待定義」的原因、是否能修、以及需要什麼才能完成。
原則（CLAUDE.md 硬規則）：**未定義的口徑不自行發明、請款金額欄不讀**，所以凡涉及這兩點的都需要業主裁示或權限，不在本次程式修改範圍。

---

## R02 業主進度（`components/OwnerProgress.tsx`）— 兩欄「待定義／—」

**現況**：進度 % 欄固定顯示「待定義」；距交期（天）欄固定顯示「—」。

**原因**
1. **進度 % — 口徑未定義（業主待裁示）**：分子／分母由誰算、以營業額還是工項、確認單營業額基準，業主 2026-10-13 明示「先不算，之後依 V4 邏輯加上」。這是**業主決策**，不是資料或程式問題。
2. **距交期（天）— 交期欄位不在手上的資料表**：`OwnerProgress` 只拿到「內業工作單」那張表（`GroupBoard` 的 `view.data`），在其中用欄名找 `交期／合約交期／預定完成日／完工期限／到期日`，但工作單本來就沒有交期欄；交期其實在
   - **報價總表**（`quotes`，`tblENZvYAya93Twa`）的白名單欄：`外業期限`、`內業期限(圖)`、`內業期限(控)`、`內業期限(報)`、`確認單到期日`、`合約結束日期`；或
   - **案件表**（`v3-cases`，`tblWsSaOcy4nKuGI`）。

**能不能修**：距交期**技術上可做**，但有兩個阻擋點：
- 需要把報價總表／案件表的交期**跨 Base join** 到內業案件（`OwnerProgress` 目前沒有這些資料，要讓 `GroupBoard` 多讀一個來源並下傳）。
- **要用哪一個期限**（圖／控／報／確認單到期／合約結束）屬於口徑，業主未定——依硬規則不自行選。

**待辦（給業主／後續）**
- 業主定義：進度 % 的分子分母；距交期要對哪一個期限欄。
- 定義後：`GroupBoard` 增讀 `quotes` 或 `v3-cases` 的期限欄，以案件編號／工程（前 7 碼）join，傳給 `OwnerProgress`；報價總表的期限欄已在 `quotesField` 白名單內，不需放寬權限。

## R03 報告檢查（來源 `v4-internal-work`、`report-delivery`）— 沒有資料

**現況**：頁面走通用來源表檢視；兩個來源都讀不到。

**原因**
1. **`v4-internal-work`（V4 內業工作單）讀不到**：V4 Base 進階權限未開放給 PM週報 應用，讀取回 **1254302（RolePermNotAllow）**。R03 的「內業品管檢核後數據」在 V4 才有（含品管檢核、業主數量覆寫欄位）。
2. **`report-delivery`（成果送出／業主回覆）尚未定位**：`lib/reports.ts` 此來源**沒有 baseToken/tableId**——V3、V4 都還沒找到「成果送出」或「業主回覆」的正式資料表（備註已記「未找到」）。
3. **期程 N+1/N+2/N+3 口徑未定義**：N 起點、節點、日曆日或工作日、重送規則（D-05）業主未定。

**能不能修**：**不能**（本次）。缺資料存取、缺資料表、缺口徑三者皆備。

**待辦**
- 業主：開放 V4 Base 給 PM週報 唯讀角色（群組＋角色方案，見 CLAUDE.md 第 9 節待辦 6），或指出 V4 Base 的進階權限如何讓應用讀到內業工作單。
- 業主／同事：告知「成果送出／業主回覆」是否有正式資料表；有的話提供 Base/table，接到 `report-delivery`。
- 業主：定義 N+123 期程口徑。
- 需要的新權限／環境：V4 Base 唯讀角色（1254302 解除）；無新環境變數。

## R06 請款詳情（來源 `receivables`）— 沒有資料

**現況**：來源為 V3「案件應收未收」視圖（`tblWsSaOcy4nKuGI` / 視圖 `vewUGIqzfl`）；畫面常為空。

**原因**
1. **視圖本身可能為空**：備註已註明「視圖為空不代表應收為零」。目前以該視圖為唯一來源。
2. **請款金額欄依硬規則不可讀**：可請款、已請款、未收款、實際入帳、內外業成本等**金額欄**散在報價 Base，`quotesField` 白名單**刻意排除**契約價格、毛利、成本、預算、可請款、實收、紅利——這是硬規則，不得放寬。所以 R06 要的核心數字目前**在程式層被禁止讀取**。
3. **口徑未定義**：可請款未請、應收未收、成本公式（D-07）、部分請款／分次入帳／折讓／稅別，業主未定。

**能不能修**：**不能**（本次）。同時卡在硬規則（金額欄不讀）＋口徑未定＋可能要 V4／報價進階權限。

**待辦**
- 業主：裁示 R06 要呈現哪些請款欄位、是否授權讀取這些金額欄（若要做，需業主明確同意並調整白名單；在那之前維持不讀）。
- 業主：定義可請款／應收／成本公式與請款狀態分類。
- 需要的新權限：讀報價 Base 請款金額欄的授權（目前明文禁止）；可能需要 V4／報價 Base 唯讀角色（1254302）。
